# 🧠 AI Stock Intelligence Dashboard

This project is a machine learning-based stock analysis system built using Python and Streamlit.

## 🚀 Features
- Stock price visualization
- Technical indicators (RSI, Moving Average)
- Machine Learning prediction (Linear Regression)
- Sequence-based prediction model
- Portfolio simulation
- Multi-stock comparison

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas, NumPy
- Scikit-learn
- Matplotlib
- yFinance API

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
